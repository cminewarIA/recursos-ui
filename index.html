Esperando dispositivo para conectarse en su versión nativa

                

                  La versión web se mantiene a la escucha. Para proyectar la pantalla, interactuar mediante aceleración por hardware e inyectar teclado y ratón USB/Wi-Fi sin latencia, abre o instala la aplicación nativa de Linux en tu equipo.
                

              

            


            
            

              

                Tecnología de la App
                GTK 3.0 Puro Nativo
                Sin WebKit ni Electron · Consumo < 30 MB RAM
              

              

                Motor de Proyección
                Scrcpy + UHID Nativo
                Control directo por hardware USB y Wi-Fi (ADB TCP/IP 5555)
              

              

                Dispositivos Compatibles
                Teléfonos & Tablets Android
                Detección en caliente por Udev y switch de resolución virtual
              

            

          


          
          

            

              

                
¿Por qué la conexión interactiva requiere la App Nativa?

                
Explicación técnica de arquitectura del sistema operativo

              

            

            

              

                

                  

                    ⚡ Acceso de Hardware UHID
                  

                  

                    El protocolo UHID del kernel Linux (/dev/uhid) permite simular pulsaciones físicas de teclado y movimientos relativos de ratón como dispositivo USB real. Los navegadores web estándar bloquean este acceso por sandboxing de seguridad.
                  

                

                

                  

                    🚀 Scrcpy a 60 FPS con Latencia Cero
                  

                  

                    La app nativa se conecta directamente al demonio adb local mediante sockets UNIX de alta velocidad y decodifica la transmisión de vídeo H.264/H.265 por aceleración VA-API de la GPU, logrando una respuesta táctil instantánea.
                  

                

                

                  

                    🖥️ Aplicación 100% Nativa GTK3
                  

                  

                    Construida con widgets nativos puros de GNOME (sin navegadores ni iframes web internos). Ofrece monitoreo en tiempo real del silicio, soporte de pantalla completa en tecla F11 e integración en el menú del sistema Linux.
                  

                

              

            

          


          
          

            

              

                
Instalación Rápida en Linux (Debian, Ubuntu, Mint, Pop!_OS)

                
Comandos para instalar el paquete oficial descargado

              

            

            

              

                Puedes descargar e instalar el paquete recursos-cockpit_6.0.2_amd64.deb ejecutando en tu terminal:
              

              
# 1. Descargar el paquete deb directamente desde este servidor
wget http://localhost:8085/download/recursos-cockpit_6.0.2_amd64.deb -O recursos-cockpit_6.0.2_amd64.deb

# 2. Instalar el paquete y resolver automáticamente dependencias (GTK3, Scrcpy, ADB, Psutil)
sudo apt-get update && sudo apt-get install -y ./recursos-cockpit_6.0.2_amd64.deb

# 3. Iniciar la aplicación nativa desde la terminal o desde el lanzador de aplicaciones del escritorio
recursos-cockpit
