03 · Topología LAN/WAN y Mapa Geoespacial

Distribución de Enlaces ASUS AiMesh, Filtrado Docker y GeoIP Libre

Explora cómo el backend combina SSH cifrado AES-256-GCM al router principal con la tabla ARP filtrada y Pi-hole FTL sin depender de APIs de pago.

Algoritmo de Deduplicación en 2 Pasadas (Cero Falsos Positivos)
1. Se excluyen interfaces virtuales Docker (docker0, br-*, veth*, tailscale*) en ip neigh.
2. Pasada 1: se registran primero todos los clientes Wi-Fi en /tmp/clientlist.json de cada nodo AiMesh.
3. Pasada 2: solo entran como Cable LAN las MACs en brctl showmacs br0 / wired_mac ausentes de la pasada Wi-Fi.

07 · Mapa de Vistas React 19 e Historial

Navegación Unificada en 5 Bloques y Criterio Semántico

Resumen de las pantallas del panel v12 y regla estricta de incremento MAJOR.MINOR.PATCH.

1. Inicio (/inicio)

Salud global, gráficas en vivo CPU/RAM/GPU/Almacenamiento, dispositivos LAN/WAN con WoL y apagado remoto.

2. Equipo (/equipo)

Núcleos lógicos, RAM+ZRAM, temperaturas térmicas del silicio, particiones montadas y Top procesos.

3. Red y seguridad (/red)

Mapa GeoIP OpenStreetMap + Leaflet, sockets activos, clientes Pi-hole, ASUS AiMesh y Fail2ban IPS.

4. Programas (/programas)

Contenedores Docker en vivo, unidades Systemd, qBittorrent, Emby y Bot de Telegram.

5. Más (/mas)

Actualizador GitHub OTA, Aspecto Claro/Oscuro, Dispositivos conectados, DeX USB (Ubuntu) y Manual interactivo.

Criterio VERSION

X.0.0 rediseño global · 0.X.0 función nueva o rediseño parcial · 0.0.X optimizaciones y bugfixes.
