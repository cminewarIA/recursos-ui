# Reglas y Pautas del Proyecto (Dashboard / Recursos)

## Publicación Automática en GitHub
- **Regla obligatoria**: Cada vez que se realice cualquier modificación en los archivos de la web o backend del dashboard (`static/index.html`, `server.py`, configuración, etc.), se deben confirmar los cambios y hacer `git push` automáticamente al repositorio de GitHub:
  - Repositorio remoto: `https://github.com/cminewarIA/recursos-ui`
  - Rama: `main`
- **Objetivo**: Mantener permanentemente sincronizado el proyecto con Google AI Studio y el móvil para permitir la edición remota y la descarga inmediata de cambios.
